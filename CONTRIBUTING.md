# Contributing

OnPresence is maintained by one person and is **not accepting pull requests** yet. Pull requests from outside the project are closed automatically. This may change later.

You can still help:

- **Bug reports:** open an issue with the bug report form. Include your version (`onpresence --version` or the image tag) and steps to reproduce.
- **Security problems:** do not open an issue. See [SECURITY.md](SECURITY.md).
- **Forks:** the code is MIT licensed. Fork it and make it your own.

Issues and pull requests written by AI agents or bots are closed without review.
