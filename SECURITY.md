# Security policy

Please **do not open a public issue** for security problems. Report them privately through GitHub: **Security → Report a vulnerability** on this repository.

Include the version (`onpresence --version` or the image tag), what you found, and how to reproduce it. You will get an answer within a week. Fixes are released as a new version and credited in the release notes unless you prefer otherwise.

Supported versions: the latest release.
